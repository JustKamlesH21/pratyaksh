# No voice biometrics, and Response audio is not kept

Pratyaksh never enrols a voiceprint and never compares a Caller's voice to a stored one; a good Clone defeats that by design, and stored voice templates are sensitive personal data under the DPDP Act. Response audio is scored in memory and discarded; only Signals, Reasons and Verdicts go into the Audit Trail. Set `RETAIN_AUDIO=true` only for collecting Eval Run recordings with consent.
