# The LLM never decides a Verdict

Challenges are chosen by a scripted state machine and Verdicts come only from the Policy over measured Signals. The LLM (Ollama) may talk about anything: it understands utterances the keyword rules miss and answers questions, grounded in `knowledge.yaml`. It never decides a Verdict, never skips or reorders a Challenge, never states account data, and its replies are dropped if they contain digit strings. Questions during a Challenge are capped so talking never buys a Clone extra tries. An LLM-driven Verification would sound more natural, but its Verdicts could not be explained with Reasons, reproduced in an Eval Run, or defended to a bank, so we gave that up.
